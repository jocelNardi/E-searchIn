# E-searchIn
Application dédiée pour trouver les besoins dans le pays

## Description

E-searchIn est une application web qui facilite la recherche de services pour les visiteurs d'un lieu. L'application permet de trouver facilement des hôtels, des chauffeurs, des locations de véhicules, et bien plus encore.

## Catégories Disponibles

- 🏨 **Hôtels** - Trouvez les meilleurs hôtels pour votre séjour
- 🚗 **Chauffeurs** - Réservez un chauffeur professionnel
- 🚙 **Locations** - Louez des véhicules pour vos déplacements
- 🍽️ **Restaurants** - Découvrez les meilleurs restaurants locaux
- 🗺️ **Guides Touristiques** - Explorez avec des guides expérimentés
- 🎯 **Activités** - Découvrez des activités passionnantes
- 🛍️ **Shopping** - Trouvez les meilleurs magasins et marchés
- 🔧 **Services** - Accédez à divers services locaux

## Démarrage Rapide

### Frontend

```bash
cd frontend
npm install
npm run dev
```

L'application sera accessible sur http://localhost:5173

Pour plus de détails, consultez le [README du frontend](./frontend/README.md).

## Technologies

- **Frontend**: React 19, TypeScript 5.9, Tailwind CSS 4.1, Vite 7.1
